# 🎧 Nibrass : l'anglais en chansons

Écris le titre d'une chanson en anglais que tu aimes. L'IA (Claude) te donne :
- la **traduction** de la chanson, partie par partie, et ses vers clés traduits ;
- les **points de grammaire** de la chanson, avec des exercices ;
- le **vocabulaire** à retenir (prononciation audio, flashcards, révisions espacées) ;
- un **quiz du jour** construit à partir de ce que tu as fait dans la journée, plus un **journal**.

**Site :** https://vbcczpv85f-alt.github.io/Anglais/

## Mise en route
1. Ouvre le site, puis **⚙︎ Réglages**.
2. Colle ta clé API Claude (à créer sur https://console.anthropic.com/settings/keys, avec un peu de crédit). Elle reste dans ton navigateur.
3. Va dans **Chansons**, écris un titre, et la leçon se crée toute seule.

Tes données sont enregistrées dans ton navigateur. Le bouton « Télécharger une sauvegarde » des Réglages permet de les garder.
